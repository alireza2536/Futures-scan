# Futures Scan

اسکن هوشمند ارزها در فیوچرز

هدف پروژه: ساخت اسکنر مستقل با رابط وب، موتور بررسی و اتصال به صرافی‌ها.

## وضعیت فعلی
- مخزن جدید است و پیاده‌سازی کامل موتور اسکن و رابط کاربری هنوز انجام نشده است.
- تست اتصال عمومی API فیوچرز OKX و MEXC در GitHub Actions اضافه شده است.
- تست اتصال، وجود قرارداد BTC-USDT و دریافت کندل‌های ۱۵ دقیقه، ۴ ساعت و روزانه را بررسی می‌کند.
- این تست فقط سلامت دریافت داده را می‌سنجد و به‌تنهایی تأییدکننده صحت محاسبات اندیکاتورها یا شرایط معاملاتی نیست.
- فقط منطق لانگِ تأییدشده اضافه می‌شود؛ منطق شرت تا زمان تعریف شرایط توسط کاربر اضافه نخواهد شد.

## اجرای تست اتصال
در GitHub به بخش Actions و سپس **Exchange API connectivity** برو و **Run workflow** را اجرا کن. این گردش‌کار بعد از هر تغییر مرتبط در فایل تست نیز اجرا می‌شود.

## دامنه‌های API
- OKX: ابتدا دامنه EEA و سپس دامنه عمومی آزمایش می‌شود؛ انتخاب نهایی باید با منطقه ثبت حساب OKX مطابقت داشته باشد.
- MEXC Futures: از دامنه جدید `https://api.mexc.com` استفاده می‌شود.

## محدودیت مهم داده
برای محاسبه EMA500 و CCI(1200)، دریافت چند کندل کافی نیست. مرحله بعد باید تاریخچه کافی را با صفحه‌بندی و کنترل محدودیت هر API دریافت کند؛ تا آن زمان هیچ سیگنال معاملاتی نباید صرفاً بر اساس تست اتصال تولید شود.
