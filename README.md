# Futures Scan

اسکن هوشمند ارزها در فیوچرز

## وضعیت پیاده‌سازی
- اتصال عمومی API فیوچرز OKX و MEXC آزمایش شده است.
- دریافت تاریخچه کندل‌ها با صفحه‌بندی برای OKX و بازه زمانی برای MEXC پیاده‌سازی شده است.
- محاسبه EMA و CCI و تست‌های قطعی فرمول‌ها پیاده‌سازی شده‌اند.
- موتور اسکن دستی لانگ برای قراردادهای پرپچوال USDT در OKX و MEXC اضافه شده است.
- خروجی اسکن شامل نمادهای منطبق، مقادیر close، EMA500، CCI1200 و خطاهای دریافت داده است.
- رابط کاربری وب هنوز ساخته نشده است؛ این مرحله موتور اسکن و اجرای دستی از GitHub Actions را فراهم می‌کند.

## فیلتر اولیه ورود ارز به اسکن
پیش از دریافت تاریخچه کندل، هر قرارداد فعال USDT perpetual باید از هر دو شرط عبور کند:
- دارایی پایه، استیبل‌کوین دلاری نباشد.
- قیمت آخرین معامله حداکثر ۳۰ USDT باشد؛ قیمت دقیقاً ۳۰ مجاز است.
- اگر قیمت در دسترس نباشد، مجوز ورود صادر نمی‌شود و هیچ تاریخچه کندلی برای آن نماد درخواست نمی‌شود.

این مرحله مستقل از جهت بازار است و هیچ شرط LONG/SHORT در آن دخالت ندارد. در این نسخه اجرایی، فیلتر روی مسیرهای OKX و MEXC که فعلاً در موتور اسکن پشتیبانی می‌شوند اعمال شده است.

## شرط معاملاتی مجاز در این مرحله
فقط شرط صریح کاربر اجرا می‌شود:
- تایم‌فریم ۴ ساعته
- قیمت بسته‌شدن آخرین کندل کامل بالاتر از EMA500
- CCI با طول 1200 بالاتر از +100

هر دو شرط باید هم‌زمان برقرار باشند. هیچ شرط شرت، امتیازدهی، رتبه‌بندی یا فیلتر معاملاتی دیگری در موتور وجود ندارد. کندل باز در محاسبه لحاظ نمی‌شود.

## اجرای اسکن کامل
1. در GitHub مخزن را باز کن و وارد Actions شو.
2. workflow با نام **Manual Futures Long Scan** را انتخاب کن.
3. روی Run workflow بزن.
4. برای اسکن کامل، مقدار `max_symbols` را `0` نگه دار.
5. صرافی‌ها به‌صورت پیش‌فرض `OKX,MEXC` هستند. مقدار concurrency پیش‌فرض 2 است تا فشار درخواست‌ها کنترل شود.
6. بعد از اتمام اجرا، فایل artifact با نام `futures-long-scan-results` را از همان اجرای workflow دریافت کن.

برای تست محدود می‌توانی max_symbols را عددی مثل 2 قرار بدهی. این محدودیت فقط برای آزمایش است و اسکن کامل نیست.

## فایل‌ها
- `scripts/market-data.mjs`: دریافت و نرمال‌سازی کندل‌های OKX و MEXC
- `scripts/indicators.mjs`: محاسبه EMA و CCI
- `scripts/strategy.mjs`: منطق لانگ دقیقاً مطابق شرط‌های تأییدشده
- `scripts/scan-long.mjs`: دریافت فهرست قراردادها و اجرای اسکن
- `scripts/test-indicators.mjs` و `scripts/test-strategy.mjs`: تست‌های ریاضی و منطقی
- `scripts/check-history.mjs`: بررسی تاریخچه واقعی و محاسبه اندیکاتورها
- `scripts/check-exchanges.mjs`: تست اتصال و فهرست قراردادها

## محدودیت‌ها و اعتبارسنجی
- EMA500 و CCI1200 به حداقل 1200 کندل معتبر نیاز دارند؛ موتور برای انتخاب آخرین کندل بسته، تاریخچه بیشتری دریافت می‌کند.
- در صورت ناکافی بودن تاریخچه یا خطای API، نماد با وضعیت DATA_ERROR ثبت می‌شود و سیگنال ساختگی تولید نمی‌شود.
- فقط OKX و MEXC در این مرحله پشتیبانی می‌شوند؛ صرافی دیگری بدون تست اتصال و تاریخچه به موتور اضافه نشده است.
- مقایسه نهایی مقادیر با TradingView هنوز باید جداگانه با نماد و کندل هم‌زمان انجام شود.
- این مخزن هنوز رابط کاربری وب، دکمه بررسی/لغو و مدیریت صف اسکن ندارد.
