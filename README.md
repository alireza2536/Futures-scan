# Futures Scan

اسکن هوشمند ارزها در فیوچرز

## مرحله اول: مجوز ورود اطلاعات
هر قرارداد فعال پرپچوال با تسویه USDT، قبل از دریافت تاریخچه کندل و ورود به چرخه اسکن، از این دو شرط عبور می‌کند:

1. دارایی پایه استیبل‌کوین دلاری نباشد.
2. قیمت واقعی دارایی پایه حداکثر ۳۰ USDT باشد؛ قیمت دقیقاً ۳۰ مجاز است.

قیمت قراردادهای ضریب‌دار مانند 1000SHIB به قیمت یک واحد دارایی پایه تبدیل می‌شود. اگر قیمت قابل دریافت نباشد، نماد مجوز ورود نمی‌گیرد. نمادهای ردشده کندل و داده‌های تحلیلی دریافت نمی‌کنند و در داده‌های ذخیره‌شونده وارد نمی‌شوند.

## مرحله دوم: شرایط LONG
شرایط هر تایم‌فریم فقط وقتی بررسی می‌شود که آن تایم‌فریم انتخاب شده باشد:

- **4h:** قیمت بسته‌شدن بالاتر از EMA500 و CCI(1200) بالاتر از +100
- **2h:** قیمت بسته‌شدن بالاتر از EMA2000 و CCI(1200) بالاتر از +100
- **1h:** قیمت بسته‌شدن بالاتر از EMA2000 و CCI(1200) بالاتر از +100
- **15m:** CCI(1200) بالاتر از +170 و EMA9 بالاتر از VWAP و EMA21
- **1d:** قیمت بسته‌شدن بالاتر از EMA20 و EMA50

اگر چند تایم‌فریم انتخاب شوند، همه شرط‌های انتخاب‌شده باید هم‌زمان برقرار باشند (AND). هیچ شرطی برای SHORT تعریف نشده است؛ امتیازدهی یا Score نیز وجود ندارد.

## وضعیت فعلی موتور
- دریافت و اسکن اجرایی فعلاً برای OKX و MEXC پیاده‌سازی شده است.
- فهرست هفت صرافی در اسکریپت آزمون API به‌صورت جداگانه بررسی می‌شود؛ موفقیت آزمون API به معنی تکمیل اتصال هر هفت صرافی به موتور اسکن نیست.
- رابط کاربری وب و دکمه‌های LONG/SHORT هنوز ساخته نشده‌اند. انتخاب تایم‌فریم فعلاً از ورودی workflow انجام می‌شود.
- داده‌های موردنیاز با تعداد کندل کافی دریافت می‌شوند؛ کندل باز در محاسبه لحاظ نمی‌شود.
- اگر داده کافی یا معتبر نباشد، نماد با وضعیت DATA_ERROR ثبت می‌شود و سیگنال ساختگی تولید نمی‌شود.

## اجرای اسکن دستی
1. مخزن را در GitHub باز کن و وارد Actions شو.
2. workflow با نام **Manual Futures Long Scan** را انتخاب کن.
3. در ورودی `timeframes` یک یا چند مورد از `15m,1h,2h,4h,1d` را وارد کن.
4. برای اسکن کامل، `max_symbols` را `0` نگه دار.
5. صرافی‌های اجرایی فعلی `OKX,MEXC` هستند.
6. پس از اتمام، artifact با نام `futures-long-scan-results` را دریافت کن.

## فایل‌های اصلی
- `scripts/initial-filter.mjs`: فیلتر اولیه استیبل‌کوین و قیمت
- `scripts/market-data.mjs`: دریافت و صفحه‌بندی کندل‌های OKX و MEXC
- `scripts/indicators.mjs`: EMA، CCI و VWAP
- `scripts/strategy.mjs`: شرایط LONG و ترکیب AND تایم‌فریم‌ها
- `scripts/scan-long.mjs`: دریافت قراردادها، اجرای فیلتر و اسکن
- `scripts/test-initial-filter.mjs`, `scripts/test-indicators.mjs`, `scripts/test-strategy.mjs`: آزمون‌های فیلتر، اندیکاتورها و منطق
