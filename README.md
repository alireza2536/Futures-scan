# Futures Scan

اسکن هوشمند ارزها در فیوچرز

## وضعیت پیاده‌سازی
- لایه دریافت داده برای هفت صرافی MEXC، BingX، OKX، WEEX، HTX، KuCoin Futures و XT آماده شده است.
- بازارهای فعال پرپچوال با تسویه USDT از متادیتای هر صرافی دریافت می‌شوند. برای OKX و MEXC مسیرهای مستقیمِ قبلاً اعتبارسنجی‌شده حفظ شده و برای پنج صرافی دیگر از آداپترهای CCXT استفاده می‌شود.
- تاریخچه کندل‌ها صفحه‌بندی، نرمال‌سازی و از نظر OHLC و بسته‌شدن کندل اعتبارسنجی می‌شود.
- اسکن کامل نمادها پیش‌فرض است؛ مقدار max_symbols برابر 0 یعنی بدون سقف مصنوعی. مقدار مثبت فقط برای تست محدود اعمال می‌شود و به‌صورت جداگانه برای هر صرافی است.
- فرمول‌های EMA و CCI و تست‌های آن‌ها حفظ شده‌اند.
- رابط کاربری وب هنوز ساخته نشده است؛ این مرحله موتور اسکن دستی از GitHub Actions را فراهم می‌کند.

## شرط معاملاتی فعلی
فقط شرط لانگ ۴ ساعته تأییدشده اجرا می‌شود:
- قیمت بسته‌شدن آخرین کندل کامل ۴ ساعته بالاتر از EMA500
- CCI با طول 1200 بالاتر از +100

هر دو شرط باید هم‌زمان برقرار باشند. هیچ شرط شرت، امتیازدهی، رتبه‌بندی یا فیلتر معاملاتی جدیدی اضافه نشده است. تغییر این مرحله محدود به لایه دریافت داده و پشتیبانی صرافی‌هاست.

## اجرای اسکن هفت صرافی
1. مخزن را در GitHub باز کن و وارد Actions شو.
2. workflow با نام **Manual Futures Long Scan** را انتخاب کن.
3. روی Run workflow بزن.
4. برای اسکن کامل، max_symbols را 0 نگه دار.
5. فهرست پیش‌فرض شامل هر هفت صرافی است.
6. پس از اتمام اجرا، artifact با نام futures-long-scan-results را از همان اجرای workflow دریافت کن.

## اعتبارسنجی و محدودیت‌ها
- اگر تاریخچه یک نماد ناکافی یا نامعتبر باشد، همان نماد با وضعیت DATA_ERROR ثبت می‌شود؛ سیگنال ساختگی تولید نمی‌شود.
- تعداد نمادها از فهرست زنده قراردادهای هر صرافی به دست می‌آید؛ سقف ثابت 100 نمادی در موتور وجود ندارد.
- PASS در تست API به معنی برقرار بودن شرط لانگ نیست؛ فقط نشان‌دهنده دسترسی به داده و امکان محاسبه است.
- مقادیر خام Open Interest بین صرافی‌ها به دلیل تفاوت واحدها قابل‌مقایسه مستقیم نیستند.
- تأیید کامل اتصال به معنی تضمین تاریخچه کافی برای تک‌تک نمادها نیست؛ اجرای زنده و گزارش DATA_ERRORها باید بررسی شود.

## فایل‌های اصلی
- scripts/market-data.mjs: دریافت و نرمال‌سازی تاریخچه کندل‌ها برای OKX، MEXC و CCXT
- scripts/indicators.mjs: محاسبه EMA و CCI
- scripts/strategy.mjs: منطق لانگ تأییدشده
- scripts/scan-long.mjs: دریافت قراردادها و اجرای اسکن هفت صرافی
- scripts/test-indicators.mjs و scripts/test-strategy.mjs: تست‌های ریاضی و منطقی
- scripts/check-final-seven-exchanges.mjs: تست تشخیصی هفت صرافی در پنج تایم‌فریم
