# Futures Scan

اسکن هوشمند ارزها در فیوچرز

## وضعیت پیاده‌سازی
- اتصال عمومی API فیوچرز OKX و MEXC آزمایش شده است.
- دریافت تاریخچه کندل‌ها با صفحه‌بندی برای OKX و بازه زمانی برای MEXC پیاده‌سازی شده است.
- محاسبه EMA با seed میانگین ساده اولیه و فرمول بازگشتی استاندارد پیاده‌سازی شده است.
- محاسبه CCI با Typical Price، میانگین ساده و Mean Deviation پیاده‌سازی شده است.
- تست‌های قطعی فرمول EMA و CCI در GitHub Actions اجرا می‌شوند.
- این مخزن هنوز رابط کاربری اسکنر و موتور کامل انتخاب نمادها/صرافی‌ها را ندارد.

## فایل‌ها
- `scripts/market-data.mjs`: دریافت و نرمال‌سازی کندل‌های OKX و MEXC
- `scripts/indicators.mjs`: محاسبه EMA و CCI
- `scripts/test-indicators.mjs`: تست‌های فرمول
- `scripts/check-history.mjs`: بررسی تاریخچه واقعی و محاسبه اندیکاتورها
- `scripts/check-exchanges.mjs`: تست اتصال و فهرست قراردادها

## نیاز داده برای اندیکاتورها
- EMA500 و CCI1200 به حداقل 1200 کندل معتبر نیاز دارند.
- فیلتر روزانه EMA20/EMA50 با 60 کندل آزمایش می‌شود.
- در صورت دریافت تاریخچه ناکافی یا محدودیت API، وضعیت BLOCKED گزارش می‌شود؛ هیچ مقدار ساختگی یا سیگنال جایگزین تولید نمی‌شود.
- API عمومی OKX برای صفحه‌بندی محدودیت نرخ درخواست دارد؛ کد برای پاسخ 429 تلاش مجدد انجام می‌دهد.
- MEXC برای هر درخواست حداکثر 2000 کندل برمی‌گرداند؛ برای بازه‌های بزرگ‌تر باید درخواست‌ها به قطعه‌های زمانی تقسیم شوند.

## اجرای تست
در GitHub به Actions برو و workflow با نام **Exchange API connectivity and indicator history** را باز کن. اجرای خودکار پس از تغییر فایل‌های `scripts/**` یا workflow انجام می‌شود.

## نکته اعتبارسنجی
تست‌های فعلی صحت ریاضی فرمول‌ها و دریافت داده API را بررسی می‌کنند. مقایسه نهایی مقادیر با TradingView، به‌ویژه تنظیمات seed، منطقه زمانی کندل و بسته/باز بودن آخرین کندل، هنوز باید جداگانه انجام شود.

## منطق معاملاتی
فقط شرایط لانگی که کاربر صریحاً تعیین کرده مجاز است. هیچ منطق شرت، امتیازدهی یا فیلتر معاملاتی اضافه‌ای در این مرحله ساخته نشده است.
