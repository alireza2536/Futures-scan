# Futures Scan

اسکن هوشمند ارزها در فیوچرز

## وضعیت فعلی پیاده‌سازی

این مرحله فقط برای دریافت داده بازار و محاسبه اندیکاتورهاست؛ هیچ شرط لانگ یا شورت و هیچ سیگنال معاملاتی اجرا نمی‌شود.

- دریافت قراردادهای پرپچوال فعال با تسویه USDT در OKX و MEXC پیاده‌سازی شده است.
- فیلتر ورود ارزها پیش از دریافت تاریخچه اجرا می‌شود: دارایی پایه نباید استیبل‌کوین باشد و آخرین قیمت معامله باید حداکثر ۳۰ دلار باشد.
- قیمت دقیقاً ۳۰ دلار پذیرفته می‌شود؛ قیمت بالاتر از ۳۰ دلار رد می‌شود.
- قیمت از آخرین معامله قرارداد فیوچرز همان صرافی خوانده می‌شود؛ USDT فقط به‌عنوان تقریب دلار در نظر گرفته شده است.
- اگر قیمت یا اطلاعات دارایی پایه قابل دریافت/اعتبارسنجی نباشد، نماد وارد فهرست واجد شرایط نمی‌شود.
- محاسبه EMA و CCI برای تاریخچه ۴ ساعته در موتور فعلی وجود دارد.
- رابط کاربری وب هنوز ساخته نشده است.

## فیلترهای قطعی ورود به فهرست دریافت داده

هر دو شرط باید برقرار باشند:

1. دارایی پایه استیبل‌کوین نباشد.
2. آخرین قیمت معامله قرارداد حداکثر ۳۰ دلار باشد.

این دو مورد فقط فیلتر انتخاب نماد هستند و هیچ ارتباطی با جهت لانگ یا شورت ندارند. فهرست استیبل‌کوین‌ها در `scripts/entry-filters.mjs` نگهداری می‌شود.

## اجرای اسکن داده

1. در GitHub مخزن را باز کن و وارد Actions شو.
2. workflow فعلی اسکن را اجرا کن.
3. برای دریافت همه نمادهای واجد شرایط، مقدار `MAX_SYMBOLS` را `0` نگه دار.
4. صرافی‌های پیاده‌سازی‌شده در این نسخه `OKX,MEXC` هستند.
5. خروجی `scan-results.json` تعداد نمادهای بررسی‌شده، ردشده، آماده داده و دارای خطا را جداگانه گزارش می‌کند.

محدودیت `MAX_SYMBOLS` فقط برای تست است و بعد از اعمال دو فیلتر ورود اجرا می‌شود؛ مقدار صفر یعنی بدون سقف تعداد نماد.

## فایل‌ها

- `scripts/market-data.mjs`: دریافت و نرمال‌سازی کندل‌های OKX و MEXC
- `scripts/entry-filters.mjs`: فیلتر استیبل‌کوین و سقف قیمت ۳۰ دلار
- `scripts/indicators.mjs`: محاسبه EMA و CCI
- `scripts/scan-long.mjs`: نام فایل فعلی حفظ شده تا اتصال workflow موجود نشکند؛ محتوای آن اکنون فقط داده و اندیکاتور جمع‌آوری می‌کند و سیگنال نمی‌سازد.
- `scripts/test-entry-filters.mjs`: تست فیلترهای ورود

## محدودیت‌ها و کارهای باقی‌مانده

- فقط OKX و MEXC در کد فعلی این مخزن پیاده‌سازی شده‌اند؛ تأیید ۷ صرافی هنوز کامل نشده است.
- تایم‌فریم‌های فعلی این اسکریپت هنوز به‌طور کامل توسعه نیافته‌اند؛ ۵ دقیقه و سایر تایم‌فریم‌ها باید در مرحله توسعه دریافت داده اضافه و جداگانه آزمایش شوند.
- VWAP هنوز در ماژول اندیکاتورها پیاده‌سازی نشده است.
- این مخزن هنوز رابط کاربری وب و انتخابگر تایم‌فریم‌ها را ندارد.
- مقایسه نهایی اندیکاتورها با TradingView باید جداگانه با نماد و کندل هم‌زمان انجام شود.
