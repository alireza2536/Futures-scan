# Futures Scan

اسکن هوشمند ارزها در فیوچرز

هدف پروژه: ساخت اسکنر مستقل با رابط وب، موتور بررسی و اتصال به صرافی‌ها.

## وضعیت
- مخزن تازه ایجاد شده؛ پیاده‌سازی موتور اسکن و رابط کاربری هنوز انجام نشده است.
- فقط منطق لانگِ تأییدشده اضافه می‌شود؛ منطق شرت تا زمان تعریف شرایط توسط کاربر اضافه نخواهد شد.
